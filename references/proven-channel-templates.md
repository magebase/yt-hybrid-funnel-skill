## How the Evolution Loop Uses This Catalog

1. **Initial Assignment:** Each channel in `channels/` is initialized with a primary template from `T-01` through `T-36` in its `brand_kit.json`.
2. **Cross-Pollination (Mutation):** When a template achieves **Alpha Winner ($S_w \ge 75$)** on one channel, `01_ingest_metrics.py` flags its pacing cadence and hook syntax so sister channels can test a hybrid variant (e.g., combining `T-01` 3D Forensic Cutaway visuals with `T-12` Noir Corporate storytelling).
3. **Automatic Template Replacement ("Kill the Losers"):** If a channel's assigned template records $S_w < 45$ for 3 consecutive production runs, the pipeline automatically retires that template for that channel and promotes the highest-RPM compatible template from the same category.
